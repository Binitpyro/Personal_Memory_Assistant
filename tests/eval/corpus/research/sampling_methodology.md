# Methodology: how I picked the test set

I did not want to evaluate on the same sequences that motivated the changes,
so I held out the last four shots of the second act entirely. They were
chosen before I looked at any results, which matters more than the number of
them.

Where a measurement needed a baseline I recorded it before touching the code
rather than reconstructing it afterwards. Reconstructed baselines always
flatter the change.

Remaining worry: four is a small number and they are all interiors.
