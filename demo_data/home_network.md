# Home network setup

## Wi-Fi
The 5 GHz network is on channel 36. Channel 149 kept dropping in the evenings,
probably because the neighbours use it too. The 2.4 GHz network is only for the
printer and the smart plugs.

## Fixed addresses
- Printer: 192.168.50.20
- Network storage box: 192.168.50.30
Everything else gets its address automatically.

## Backups
The laptop backs up to the network storage box every night at 02:00. Once a
month I copy the backup folder to an external drive that lives in a drawer at
work, so one copy is always off-site.

## Things to remember
- After a power cut, restart the router first, then the storage box.
- The guest network turns itself off at midnight.
